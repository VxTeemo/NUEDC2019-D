# 2019年全国大学生电子设计竞赛 D题 - 简易电路特性测试仪

## 项目简介

本项目是2019年全国大学生电子设计竞赛D题"简易电路特性测试仪"的实现方案，基于2018年开发的电子测量系统平台进行扩展。该测试仪能够对给定的双口网络放大电路进行自动测试，包括频率特性、输入输出阻抗、放大倍数测量以及电路故障检测等功能。

## 赛题要求

### 任务描述
设计并制作一个简易电路特性测试仪，用于测试题目规定的双口网络放大电路的相关参数。

### 主要功能要求
1. **频率特性测量**：测量放大电路的幅频特性曲线，频率范围100Hz~1MHz
2. **输入阻抗测量**：在1kHz频率下测量放大电路的输入阻抗
3. **输出阻抗测量**：在1kHz频率下测量放大电路的输出阻抗
4. **放大倍数测量**：在1kHz频率下测量放大电路的电压放大倍数
5. **上限截止频率测量**：测量放大电路的上限截止频率（-3dB点）
6. **故障检测**：检测电路中元器件（R1~R4、C1~C3）的开路和短路故障

## 硬件平台

- **主控芯片**：STM32F407ZGT6 (ARM Cortex-M4)
- **显示屏**：TFT LCD触摸屏
- **AD转换**：ADS1256 (24位高精度ADC)
- **信号源**：AD9851 DDS信号发生器
- **继电器模块**：用于切换测量通道和负载

## 主要功能模块

### 1. 频率特性测量
- 使用AD9851 DDS产生100Hz~1MHz的扫频信号
- 通过ADS1256高精度ADC采集输出信号
- 绘制幅频特性曲线并显示在LCD屏幕上
- 自动识别上限截止频率（-3dB点）

### 2. 阻抗测量
- **输入阻抗测量**：通过串联已知电阻分压法测量
- **输出阻抗测量**：通过接入/断开负载电阻测量输出电压变化

### 3. 故障检测
支持检测以下故障类型：
- R1~R4电阻开路/短路
- C1~C3电容开路/短路（容值加倍）

检测方法：
- 直流工作点分析
- 交流信号响应分析
- 多频率测试综合判断

## 使用说明

### 编译与烧录
1. 使用Keil MDK打开`Competition2019.uvprojx`工程文件
2. 编译工程（Build → Rebuild All）
3. 连接调试器，下载程序到目标板

### 操作方法
1. 将被测电路连接到测试仪接口
2. 开机后系统自动进入测量界面
3. 系统自动完成以下测量：
   - 输入阻抗
   - 输出阻抗
   - 1kHz放大倍数
   - 频率扫描与特性曲线绘制
   - 上限截止频率
4. 按KEY2切换到故障检测模式

## 技术特点

1. **高精度ADC**：采用24位ADS1256，保证测量精度
2. **DSP数学库**：使用ARM Cortex-M4的DSP库进行FFT运算
3. **简易RTOS**：自研轻量级多任务操作系统
4. **图形化显示**：TFT LCD实时显示幅频特性曲线
5. **触摸操作**：支持触摸屏交互
